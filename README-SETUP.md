# 39LPeter Poster & Motion Portfolio

This is a responsive purple-gradient portfolio gallery using image and video assets from:
https://github.com/39LPeter/Portofolio-graphicdesigner-/tree/main/assets

## Publish with GitHub Pages

1. Download and unzip the portfolio package.
2. Create a new GitHub repository named `poster-portfolio` (or choose another name).
3. Upload `index.html` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. After GitHub Pages publishes it, the URL will be `https://39LPeter.github.io/poster-portfolio/` if the repository is named `poster-portfolio`.
7. Add that URL to your profile README.

## Notes

- The gallery loads artwork from the existing `39LPeter/Portofolio-graphicdesigner-` repository using raw GitHub URLs. Keep the source assets public and preserve their exact filenames.
- Video projects use the browser's native video controls.
- The category filters, next/previous controls, dots, and autoplay work on desktop and mobile.
- The cat GIF is retained in the footer.
